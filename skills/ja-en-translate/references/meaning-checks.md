# Meaning Checks

Three checks that keep a translation or a rewrite from changing what the source says. They run on every sentence that was restructured, split, merged, or toned down, and in refined mode on the whole draft.

Contents: Sentence types · Six-point test · Modality strength table

## Sentence types

Before translating or rewriting, note what each sentence *does*. After, check that it still does the same thing. Keep the note internal; do not put it in the output.

| Type | Japanese markers | English markers | Typical failure |
|---|---|---|---|
| Fact | 〜である / 〜した | is / did | turned into opinion by an added "arguably" |
| Opinion or evaluation | 〜と思う, 〜と考える, 〜が大事だ | I think, it is important | stated as fact; or evaluation turned into a goal ("〜が大事" → "aims to") |
| Request or rule | 〜してください, 〜すること, 〜しなければならない | please, must, shall | softened into a description, or a description hardened into a rule |
| Metaphor | 〜のようだ, まるで | like, as if | made literal ("まるで戦場のようだ" → "it was a battlefield") |
| Irony or rhetorical question | 〜だろうか (反語) | rhetorical "Who would…?" | turned into a real question |
| Hypothesis or prediction | 〜なら, 〜だろう, 〜かもしれない | if, would, may | turned into a plan or a certainty |
| Hearsay or quotation | 〜とされる, 〜らしい, 〜という, 〜によれば | reportedly, X says | turned into the writer's own assertion |

If a type changed, restore it. If the target language cannot express it the same way, keep the closest form and note the loss in the analysis or critique. Where the author deliberately leaves two readings open (fiction, humanities prose), keep both open.

## Six-point test

For each restructured sentence, write the new version, then compare it with the source on six points. If any point changes, discard the new version and translate more literally (or, in polish, keep the original and list it under "Please confirm").

1. **Topic**: what the sentence is about
2. **Affirmed and denied**: what it says is so, what it says is not so (including 〜ではなく contrasts that carry meaning)
3. **Actors**: who does what to whom
4. **Scope and conditions**: limits, exceptions, quantities, "only", "all", "some"
5. **Strength**: assertion, inference, possibility, hearsay (see the table below)
6. **Specifics**: numbers, names, dates, units, citations

Filling an unstated subject from context, and splitting a long sentence while keeping its connective, do not change any of the six points and are allowed.

## Modality strength table

Permission, ability, obligation, and guarantee are part of the content. In specifications, terms, and rules they *are* the specification. Map them deliberately in every context, not only `official`.

| Meaning | Japanese | English | Do not confuse with |
|---|---|---|---|
| Obligation | 〜しなければならない, 〜すること（規程）, 〜必須 | must, shall (legal), is required to | should (advice) |
| Prohibition | 〜してはならない, 〜しないこと, 〜禁止 | must not, shall not | should not (advice) |
| Advice | 〜したほうがよい, 〜することを推奨 | should, it is recommended | must |
| Permission | 〜してよい, 〜しても構わない | may, is allowed to | can (ability) |
| Ability or availability | 〜できる | can, is able to | may (permission) |
| Optionality | 任意, 〜してもしなくてもよい | optional, may … or not | recommended |
| Guarantee | 必ず〜する, 〜を保証する | always, guarantees, will | usually |
| Possibility | 〜場合がある, 〜ことがある, 〜可能性がある | may, can sometimes, might | always (dropping 場合がある) |
| Inference | 〜と考えられる, 〜だろう | likely, probably, suggests | is (assertion) |
| Hearsay | 〜とされる, 〜らしい, 〜そうだ | reportedly, is said to | is (assertion) |

Rules:
- Never add 必ず / always / guarantees, and never drop 場合がある / may sometimes, for fluency.
- 〜することができる → 〜できる is the same strength and is allowed; 〜してよい → 〜できる is not.
- In `technical` and `official` contexts, any change in this table is a **critical** finding in the critique.
