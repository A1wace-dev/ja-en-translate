# Context: casual

Chat messages, LINE/Slack/Discord, social media replies, personal emails and notes between friends, comments.

## Defaults

| Setting | Value |
|---|---|
| Japanese style | Plain form (タメ口) between friends; です・ます for acquaintances, 先輩, or first contact |
| Keigo | `none` or `teinei` depending on the relationship |
| English | Conversational, contractions, natural fillers |
| Notes | `none` |
| Restructuring | High; aim for what a native speaker would actually type |

## Core stance

**Match the relationship.** The same request reads differently to a close friend, a 先輩, and a new classmate. If the relationship is unclear and the register choice matters, ask once (who is it for?).

## JA→EN

- Sentence-final particles carry tone: 〜よね (seeking agreement → "right?"), 〜じゃん ("you know"), 〜かな (soft wondering → "I wonder if" / "maybe").
- Japanese softeners (ちょっと, 〜けど…, 〜かも) → English softeners (kinda, just, I think), not literal.
- Emoticons and kaomoji: keep; (笑) / w / 草 → "lol" / "haha".
- 了解 / りょ / おけ → "got it" / "ok" / "kk".

## EN→JA

- "lol" → (笑) or w (match the user's style).
- Avoid textbook Japanese: "That's awesome!" → それすごいね！ / めっちゃいいじゃん, not それは素晴らしいです.
- Pronouns almost never appear. "Are you coming?" → 来る？
- Gendered speech: don't add 〜わ / 〜ぜ unless the user's own style does.
- If the user writes in their own voice, keep their style (look at previous messages in the conversation when available).

## Critique focus

- Would a native speaker actually send this?
- Is the politeness level right for the relationship?
