# Context: academic

Papers, theses, abstracts, course reports (レポート), literature reviews, conference slides with academic content.

## Defaults

| Setting | Value |
|---|---|
| Japanese style | だ・である体 (reports, papers). です・ます only if the source genre uses it (e.g., 講義録, some 教育学 reports) |
| Keigo | none in body text |
| English | Formal academic register; no contractions |
| Notes | `footnote` — `[訳注]` in JA output, `[Translator's note]` in EN output, collected at the end |
| Restructuring | Low to medium. Sentence splits allowed; argument order never changes |

## Core stance

Fidelity to the **argument**: claims, scope, evidence, and the author's degree of certainty. A smooth sentence that strengthens or weakens a claim is a mistranslation.

## Rules

**Hedging and modality are content.** Map them deliberately:

| Japanese | English | Note |
|---|---|---|
| 〜と考えられる | it can be argued / this suggests | not "it is thought" (agentless and vague) |
| 〜と言えよう / 〜と言えるだろう | arguably / it may be said | |
| 〜可能性がある | may / could / there is a possibility that | |
| 〜と思われる | appears to / seems | author's own weak claim |
| 〜ではないだろうか | it may be that / one might ask whether | rhetorical, not a real question |
| 〜に他ならない | is nothing other than / is precisely | strong claim, keep strength |
| 明らかである | clearly / it is evident | |

EN→JA: "may" ≠ 〜かもしれない in academic prose (too casual) → 〜可能性がある / 〜と考えられる. "This paper argues" → 本稿は〜と論じる / 本稿では〜を論じる.

**Terminology.** Use the field's established term, not a dictionary equivalent. When unsure, state the choice in the analysis. Keep the original in parentheses on first use when the term is contested or theory-specific: 想像の共同体（imagined communities）, ハビトゥス（habitus）.

**Citations.** Keep author names, years, page numbers, and reference lists intact. Do not translate titles in the reference list; on first in-text mention, a work's title may be given as 『原題』（Original Title, Year）or *Original Title* (『原題』).

**Quotations.** If a published translation of a quoted passage exists and is known, note it; never present your own translation of a quote as the published one. Mark own translations: （引用者訳） / (my translation).

**Concepts with no equivalent** (居場所, 甘え, 世間, 共生): keep romanized in italics on first use with a gloss — *ibasho* (a place where one feels one belongs) — then use consistently.

**Japanese academic conventions (EN→JA).**
- Self-reference: "I" → 筆者 / 本稿 (not 私 unless the source is a personal essay)
- "In this paper" → 本稿では; "we" in sciences → 本研究では / 我々 (field-dependent)
- Avoid 〜することができる chains; prefer 〜できる / 〜し得る
- 体言止め is not used in body text

**English academic conventions (JA→EN).**
- Japanese papers often build to the claim; English expects the claim near the start of the paragraph. You may move a paragraph's thesis sentence forward **only in refined mode, only within a paragraph**, and record each move in the critique.
- Long 〜し、〜し、〜であり chains → split into separate sentences with explicit connectives (however, therefore) chosen from the logic, not added for decoration.

## Critique focus

- Did any claim get stronger or weaker?
- Are field terms standard and consistent?
- Is it unmistakably academic register in the target?
- Are own-translation quotes marked?

## Example

JA: 本稿は、在日外国人の「居場所」の喪失が同化圧力と不可分であることを示唆するものである。
EN: This paper suggests that the loss of *ibasho* — a place where one feels one belongs — among foreign residents in Japan is inseparable from pressure to assimilate.
(示唆する = "suggests", not "shows"; not "proves".)
